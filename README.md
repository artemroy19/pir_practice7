# Практическая работа №7

## WebFlux и RSocket

1. WebFlux в этой работе принимает HTTP-запросы. RSocket задаёт собственные модели взаимодействия и формат кадров.
2. HTTP GET возвращает HTTP-статус и JSON. RSocket Request-Response возвращает один ответ в рамках RSocket-взаимодействия.
3. HTTP/SSE отправляет события в теле одного открытого HTTP-ответа. RSocket Request-Stream передаёт элементы через кадры RSocket и поддерживает управление спросом на уровне протокола.
4. SSE передаёт данные от сервера клиенту. Для изменения статуса клиент отправляет отдельный PUT. RSocket Channel поддерживает потоки в обе стороны в рамках одного взаимодействия.
5. HTTP DELETE возвращает подтверждение 204. В модели RSocket Fire-and-Forget отдельный ответ на действие не предусмотрен.
